# Rikenomics 台本｜第4話

## メタデータ

- シリーズ名：現象の裏側シリーズ（新規）
- 話数：第4話（全体の通し話数としては4話目）
- テーマ：交通流（事故も工事もない渋滞は、ブレーキの反応の連鎖が増幅して生まれる「後ろへ進む波」）
- 見せ方：A. カメラワーク型（夜の高速の俯瞰→円環コース→波の可視化）＋B. 構造美型（光の点の流れが描く波）
- 伝え方：③問いかけ先出し型（導入）＋⑤常識くつがえし型（オチ）
- 参照する世界観ルール：なし（擬人化なし、光の点として描く車の流れそのものが被写体）
- 総コマ数（n）：6
- 絵作りの方針：車は箱や球の発光する点として描き、ブレーキ中は赤、通常走行は白〜青の光にする（キャラクター・人物モデリングは使わない）。暗い背景に光の点が流れる表現でEp2・Ep3と統一する。渋滞の波は赤い点の密度の塊として見せ、車の進行方向と逆向きに動くことが一目で分かるカメラ・配色にする。
- 精度に関する注意：2008年の円環コース実験（ドライバーに一定速度で前の車について走るよう指示）で、事故・工事などの外的要因なしに速度のゆらぎが増幅して渋滞が発生したことは確認済み。渋滞の波が車の進行と逆向きに伝わることは交通流理論の標準的な知見だが、ナレーションでは速度の数値は出さない。厳密にはカオスではなく「小さな揺らぎが増幅される不安定性」なので、ナレーションで「カオス」と言い切らない（STEM Roomのカオス理論EP1〜2の「小さな差の増幅」と接点がある扱いに留める）。対策は「車間を空けて、渋滞に近づく前に早めにゆるやかに減速する」（スローイン・ファストアウト）で、渋滞波を車間で吸収する実験も実施されている。「1台で消える」と断定せず、「波を弱められる」の表現にとどめる。

## コマ構成（起承転結）

### ①起（日常）— 使用コマ数：1
- 1a. scene：夜の高速道路を真上から見下ろした俯瞰。白と青の光の点（車）が滑らかに流れている。画面奥の一点で、突然、赤い光の点が固まりはじめる。
- text：事故も、工事もない。それなのに、なぜか渋滞が起きる。原因は何だと思う？
- 話者：ナレーション

### ②承（異変の芽）— 使用コマ数：1
- 2a. scene：円環状のコースを回る光の点の列。全員がほぼ同じ速度で走っている中で、1つの点だけがほんの少し赤くなって減速する。すぐ後ろの点は、それより少し強く赤くなって減速し、その次の点はさらに強く赤くなる。赤みが後ろへ後ろへと強まりながら伝わっていく。
- text：最初は、誰かが少しブレーキを踏んだだけ。後ろの車は、それより少し強く踏む。その反応が後ろへ後ろへ重なって、やがて車が止まる。
- 話者：ナレーション

### ③転（危機ポイント）※必須 — 使用コマ数：2
- 3a. scene：円環コースの俯瞰。白い点は前へ進み続けているのに、赤い点の塊だけが、それとは逆向きに、ゆっくり後ろへ移動していく。進行方向を示す矢印と、塊が動く矢印が逆向きに並んで表示される。
- text：車は前に進んでいる。でも渋滞は、それとは逆向きに、後ろへ進んでいく。
- 話者：ナレーション
- 3b. scene：円環コースの上に、赤い点の密度を示す光の曲線が重なる。密度の山が波の形になって、車の流れと逆向きに滑るように進んでいく。赤い塊の中の点は、入れ替わりながら通り抜けていく。
- text：渋滞は、車の塊じゃない。車が入れ替わりながら通り抜けていく、ひとつの波だった。
- 話者：ナレーション
- この危機は何のメタファーか（科学的に何が起きているか）：渋滞は特定の車の集まりではなく、車の密度が高い領域が波（密度波）として上流側へ伝わっていく現象で、個々の車は前に進みながらその波を通り抜けている。小さな減速が反応の遅れと過剰なブレーキで増幅されることで、外的要因なしに自発的に生まれる。

### ④結（オチ）※予定調和禁止 — 使用コマ数：2
- 4a. scene：赤い波が生まれかけた円環コース。1つの点が、早めに、ゆるやかに減速して車間を大きく空ける。その後ろの点の赤みが弱まり、波がだんだん薄れて、また白と青の光の流れに戻っていく。
- text：渋滞は、誰かの悪意じゃなく、みんなの小さなブレーキが重なってできる波。車間を空けて、早めにゆるやかに減速する車が増えるほど、その波は弱まっていく。
- 話者：ナレーション
- 4b. scene：光の流れが元に戻った円環コースの俯瞰。画面の隅に、「交通流理論」の文字だけが静かに浮かぶ。
- text：この波を扱う学問を、交通流理論という。
- 話者：ナレーション
- 理論名（一言）：交通流理論。呼びかけはせず、名前だけ出して終わる（③までは理論名を出していない）
- このオチの意外性は何か（一言で）：渋滞は事故や工事のような「原因」がなくても、誰の悪意もないまま自然に生まれる一方で、車間を空けて早めにゆるやかに減速する運転で弱められる。しかも自分が今日から実践できる。

## 投入前チェックリスト

- [x] **危機・対立が含まれているか**：③転で「渋滞は車の塊で、車と同じ向きに進む」という思い込みが、「車と逆向きに進む波」という事実で覆される
- [x] **オチに意外性があるか**：原因のない渋滞が自然に生まれること、そして自分の運転で弱められるという実用的な着地
- [x] **世界観ルールと矛盾していないか**：擬人化を使わないテーマのため対象外
- [x] **キャラクターに感情・性格が乗っているか**：本作は擬人化キャラクターを使わない構成のため対象外（ナレーション主体）
- [x] **科学的事実として正確か**：2008年の円環コース実験と、渋滞波が逆向きに伝わる交通流理論の標準的知見に基づく。速度の数値・「カオス」の断定・「1台で消える」の断定は避けている
- [x] **絵として成立しているか**：光の点と赤い密度の波が主役。数式・表は出さない
- [x] **入口が日常の現象か**：「事故も工事もないのに起きる渋滞」という誰もが経験した現象から入り、理論（密度波・不安定性）は③で答えとして出している
- [x] **理論名の出し方が適切か**：③までは理論名を出さず、④bの最後に「交通流理論」と名前だけ出している。「学ぼう」などの呼びかけはしていない

## 制作の決定事項（2026-10-03）

- **時間帯**：夜（ブルーアワー寄り）。参考画像は `ep4/reference/`
  - 本命：`ref_main_bluehour_straight.jpg`（深い青の空、オレンジの街灯の列、赤いテールランプ、対向車線の白いライト）
  - 補助：`ref_telephoto_endless.jpg`（望遠で地平線まで続く赤い列）
- **場所**：郊外の、合流もトンネルもない直線の高速道路。原因に見えるもの（合流・標識・信号・トンネル）を画面に入れない
- **色**：深い青の空／オレンジの街灯／赤いテールランプ／対向車線の白いライト
- **カメラ**：1aは道路と同じ高さの望遠目線で、赤い列が地平線まで続く絵から入り、上昇して真上の俯瞰へ移る
- **車の色のルール**：1aは写真どおり全車が赤いテールランプ。俯瞰に移ったところから記号表現に切り替え、
  通常走行は白〜青、ブレーキ中だけ赤にする（「表の景色」→「裏側の仕組み」の演出）
- **方針の見直し（2026-10-03）**：
  - ユーザーの指摘「ブレーキが後ろへ波及するのはみんな想像がつく。その過程を忠実に再現することが大事」により、
    交通流の計算（IDM＋反応の遅れ、`ep4/scripts/traffic_sim.py`）を観測値と照合してから絵に流し込む。円環コースは画面に出さない
    （計算上の周期境界として使い、画面はまっすぐな高速道路の一部を映す）
  - 20秒・高倍率の早送り（4〜10倍）＋カメラ移動では「早すぎて何が起こってるかわからん」。20秒で渋滞の過程を見せるのは無理筋と判断
  - 同テーマの投稿（IDM・円環・制御1台vs制御なし、いいね約5千）を参照。分かりやすさは「全体が見える固定の視点・速度の色分け・
    倍率と経過時間の表示」から来ていた。ep4は「生まれる過程を現実の景色で」に振り切り、4aの「1台で弱める」は軽く触れる程度にする
  - 「このテーマにグラフィックはそんなに重要じゃなかった」→ 冒頭（1a）だけリアルな夜の高速道路（フック・カバー用）、
