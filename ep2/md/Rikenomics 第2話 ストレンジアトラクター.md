- シリーズ名：カオス理論シリーズ（新規）
- 話数：第2話（全体の通し話数としては2話目）
- テーマ：カオス理論（ローレンツアトラクター／バタフライ効果）
- 見せ方：B. 構造美型（曲線そのものの美しさ）＋ C. データ可視化型（2つの軌跡の分岐過程）
- 伝え方：⑤常識くつがえし型（オチ）
- 参照する世界観ルール：なし（擬人化なし、数学的な軌跡そのものが被写体）
- 総コマ数（n）：5

## コマ構成（起承転結）

### ①起（日常）— 使用コマ数：1
- 1a. scene：漆黒の空間に、ほぼ同じ場所から出発した2つの発光点（片方は青、片方は白）。2つはぴったり重なって見えるほど近く、1本の線にしか見えない。
- text：この2つの点は、ほぼ同じ場所から出発する。その差は、10万分の1。
- 話者：ナレーション

### ②承（異変の芽）— 使用コマ数：1
- 2a. scene：2つの点が空間を漂いながら進んでいく。まだほとんど重なって見えるが、よく見ると刃物のように薄い隙間が生まれ始めている。
- text：最初は、ほとんど見分けがつかない。同じ軌道を、同じように進んでいるように見える。
- 話者：ナレーション

### ③転（危機ポイント）※必須 — 使用コマ数：2
- 3a. scene：隙間が急激に広がり始める。青と白の軌跡が、明確に別の方向へ分かれていく。
- text：でも、そのわずかな差は、時間とともに何倍にも膨れ上がっていく。
- 話者：ナレーション
- 3b. scene：2つの軌跡が完全に別々の場所で、全く異なる複雑な模様を描いている。もはや同じ場所から出発したとは思えないほど、離れた軌道を漂っている。
- text：気づけば、2つはまったく別の場所にいる。同じ場所から、同じ法則で動いているだけなのに。
- 話者：ナレーション
- この危機は何のメタファーか（科学的に何が起きているか）：初期値鋭敏性（カオス理論の中核）。決定論的な方程式（乱数は一切使われていない）にもかかわらず、初期値のごくわずかな差が指数関数的に拡大していく現象。「バタフライ効果」の名の由来そのもの。

### ④結（オチ）※予定調和禁止 — 使用コマ数：1
- 4a. scene：カメラが一気に引いて、全体を俯瞰する。青と白、バラバラに見えていた2つの軌跡が、実は同じ1つの蝶の羽のような形（ストレンジアトラクター）をなぞっていたことが分かる。どちらも、その形の外には一度も出ていない。
- text：ただし、2つの軌跡を遠くから見ると、まったく同じ形を描いている。どこに行くかは予測できない。それでも、どこまでも自由というわけでもない。
- 話者：ナレーション
- このオチの意外性は何か（一言で）：「予測不能」と「決まった形に収まる」は矛盾するように聞こえるが、両立する。カオスとは「ランダム」ではなく「決定論的なのに予測できない」現象であり、個々の軌道は無秩序でも、全体としては美しい構造（アトラクター）に収束する。

## 投入前チェックリスト

- [x] **危機・対立が含まれているか**：③転で、ごくわずかな初期値の差が指数関数的に拡大し、2つの軌跡が別々の場所へ引き裂かれる
- [x] **オチに意外性があるか**：「バラバラに見える軌跡が、実は同じ1つの形を描いている」という、カオス理論の本質（決定論と予測不能性の共存）で着地
- [x] **世界観ルールと矛盾していないか**：擬人化を使わないテーマのため対象外
- [x] **キャラクターに感情・性格が乗っているか**：本作は擬人化キャラクターを使わない構成のため対象外（ナレーション主体）
- [x] **科学的事実として正確か**：ローレンツ方程式・初期値鋭敏性・ストレンジアトラクターへの収束、いずれも実在するカオス理論の中核概念（カオス理論_EP1〜4参照）
