## 台本の要点（`ep5/md/Rikenomics 第5話 車と雷.md`）

- 「もしも」シリーズ。問い「もしも、あなたが落雷に見舞われたら…」、答えの一言「雷は、一番通りやすい道を選ぶ」
- レンダー30秒（900フレーム）。縦型・ナレーションなし。人は描かず、車内の明かりで「中にいる」を表す
- 本物と計算の切り替え: 1発目は本物の見え方のまま。2発目（同じ雷のリプレイ）を落ちた次のフレームで止め、止まった絵のまま色を抜いて計算した電流の筋を伸ばす。筋が出ている間は隅に「計算した電流の通り道」
- カメラ: 本物の世界（冒頭・オチ）は右斜め前・低めの定点。止まった時間（122〜540）の中でだけ動く。テロップの帯（上から11〜26%）を空け、指す物は真ん中、下25%と右下は避ける
- 数字はテロップと計器で画面に出す（投稿文は読まれない）

## 数字と出典（テロップに出すもの）

| 数字 | 根拠 |
|---|---|
| 電流 約3万A | IEC 62305-1:2010 表A.1（負極性の最初の雷撃の中央値。雷の半分はこれ以下） |
| 約2万8000℃（太陽の表面の約5倍） | 米国気象局 Lightning Science Overview（華氏5万度） |
| あなたの体を通る電流 0% | `03b_car_current.py`：窓の高さを下る電流は100%ピラー（A 13%・B 19%・C 18%ずつ）、出口は後輪31%ずつ・前輪19%ずつ |
| 人の体より数十万倍以上 通りやすい | `03b`：屋根→車輪のボディ 約0.24mΩ（鋼板0.8mm、直流）。人の体 約650〜1100Ω（IEC 60479-1 を引用した資料）で約300万〜450万倍。表皮効果で数倍〜10倍下がりうるので安全側に |
| タイヤや電装品が壊れることも | 米国気象局 Lightning and Cars |
| 木の位置（車から約41m） | 回転球体法（半径45m、杉の高さ18m → 杉が守る範囲は根元から約36m）。近すぎると1回目に車へ落ちるのが不自然。`shots.HERO_TREE_POS` |
| 杉が倒れる時間（約4秒） | 折れた点を軸に回る長さ16mの棒（θ'' = (3g/2L) sinθ）、裂けたはずみの0.06rad/sから。最初の1秒は約4°しか傾かない（「一拍おいて」は物理から出る） |

投稿文に回す補足（画面には出さない）: 電流の計算は直流であること、雷1回で屋根に最大約7mmの穴・Bピラー +0.01℃（`03e_damage_estimate.py`、IEC 62305-1 式D.7・D.9）。

## スクリプト（`ep5/scripts/`）

- `00_field_check.py`・`01_surface_current_check.py`: 着手前の計算（箱2段の車）。本番は03系
- `01_generate_scene.py`: 駐車場・山・木・オチの杉（切り株と倒れる部分）・車・雨・雷2本・蒸気・電流の筋（道のりをUVに持つ管と路面の光）・カメラを作ってWIPに保存
- `02_stillcheck_render.py`: 確認用の静止画（`full` 本番の解像度、`clear` 雨なし・明るい曇り空、`science` 科学の目と電流の筋）
- `02b_turnaround_render.py`: 車の8方向
- `03_export_car_mesh.py`: 本番の車のボディを計算用に書き出す（`ep5/cache/car_body.npz`）
- `03b_car_current.py`: ボディの表面の電流（直流）とボディの抵抗。`ep5/cache/car_current.npz`
- `03c_car_field.py`: 電場（使わないことにしたが残す）
- `03d_current_lines.py`: 電流の筋（流線48本）。`ep5/cache/current_lines.npz`
- `03e_damage_estimate.py`: 雷1回の被害と回数の見積もり（IEC 62305-1）
- `frame_state.py`: 空・コンポジター・レンダー設定と、フレームごとの状態（カメラ、雷の閃光3回、静止、雨、科学の目と筋の先端・路面の光、杉の裂けた跡・蒸気・倒れる）

- `shots.py`: 共通の定数（車の形・カメラのキー・区間・落雷とリプレイと静止のフレーム・杉）

## 気になっていること

- 木が裂ける仕組み（幹の水分が一瞬で沸騰）は解説記事どうしで一致しているが、一次情報に近い出典を探す。そのとき、実際に木へ雷が落ちた映像の記録で蒸気の見え方も確かめる
- 止まった雷の道が、どのカメラ位置でもテロップの帯を縦に通る。文字に影を付けて読めるか、テロップを入れた段階で確かめる
- 上から車内をのぞく角度（460）で、落雷点のまわりが止まった雷の点光源で白く飛ぶ。筋は見えているので今はそのまま
- 路面の光の輪は、寄ると少し大きく見える
